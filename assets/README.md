# Profile images

- `titicaca-process.gif` and `titicaca-poster.jpg`: Lake Titicaca's actual Google Maps trip view, its exact cached satellite imagery, and the original finished poster. The GIF crossfades between the three distinct images; the still shows the finished poster for reduced motion. The map and tilted relief have different projections, so their landmarks are not forced into artificial alignment.

  Credits: Google Maps ©2026 Google; contains modified Copernicus Sentinel data 2024; original road/route data © OpenStreetMap contributors, ODbL (Valhalla routing). The map screenshot retains Google's attribution. It was captured with the sidebar collapsed and presentation controls hidden, without changing map data.

  Timing: 8.64 seconds, including a 3.2-second final-poster hold. Export: 960×792 pixels, shared color palette with reserved route/pin colors.

- `terrain-still.jpg` and `terrain-workflow.gif`: an illustrated explanation of the Shaded Relief Maps pipeline alongside a real Alps terrain render. The animation is a diagram, not a recording of the rendering process. No trip routes or pins are included.
- `radio.jpg`: a purple RadioV2 banner with Discover and Favourites smartphone mockups, including Android Back, Home, and Recent Apps buttons. Device frames and banner were produced with the imagegen skill from existing app screenshots and the user's visual reference; they are presentation artwork.
- `radio-mobile.jpg`: the same banner cropped around both phones for narrower viewports.
- `radio-discover-phone.webp` and `radio-favourites-phone.webp`: individual transparent smartphone mockups for reuse.
- `radio-desktop.jpg`: the actual RadioV2 Windows screenshot, kept separately from the phone mockups.
- `attend.jpg`: Attend's existing logo and verified app features, presented as a branded project preview rather than an app screenshot.

The still images are browser-rendered compositions. The GIF has a still fallback when the reader requests reduced motion. Public profile artwork intentionally excludes local paths and source-image metadata.

Radio source screenshots: [Windows](https://github.com/Natboa/RadioV2/tree/main/Assets/screenshots), [Android](https://github.com/Natboa/RadioV2-Android/tree/main/assets/images/screenshots).
